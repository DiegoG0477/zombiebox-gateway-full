# v0.1.0-dev.66 — visible Full Compose installation

The public installer now keeps its verified release files, including
`compose.yaml`, directly in the directory where the command runs. `--directory`
chooses another directory; `--user-data` explicitly retains the previous
versioned XDG location. Existing files are not overwritten, and a previously
downloaded bundle is checked before Compose runs again.

Nine installer tests, the full 33-test Full suite, formatting, dependency pins,
shell syntax and Compose configuration passed on Fedora. These tests used a
mock Docker command for the installer; they did not pull images or start
containers. The install channel and published dev.52 images are unchanged.
Plex account linking and physical acceptance remain open.
