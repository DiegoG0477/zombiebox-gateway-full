  `e09ad252431328eb4913a3a344193c93a91af0cc`. No image or source tag moved.
- Nine GHCR manifest digests were checked with anonymous registry tokens; ten
  Compose services reference those exact digests. The seven installation assets
  (`compose.yaml`, `seccomp.json`, `release.lock.json`, `README.md`, `LICENSE`,

  GitHub asset digests matched local SHA256 values; the bundle's checksum file
  verified each payload.

  assets and verified them; its `pull`/`up` sequence was exercised with a mock Docker
  command so the running dev.22 services were unaffected.

