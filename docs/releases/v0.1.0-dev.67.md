# v0.1.0-dev.67 — operator-code location guidance

During the first external-style public dev.52 installation, the user attempted
to read `/config/operator.code` from the Linux host. The code is stored in the
gateway container's persistent named volume. The installer output and README
now explicitly say to run `docker compose exec gateway cat /config/operator.code`
from the installation directory.

The installation itself succeeded, and the gateway/YouTube containers became
healthy. This source-only checkpoint does not change the published dev.52 image
set, start another deployment or complete a physical/account milestone.
