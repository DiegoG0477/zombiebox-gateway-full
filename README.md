# Gateway Full

`make full-up` builds and starts the shared Go core and pinned MediaMTX relay. `make full-down` stops them. SQLite, configuration and media live under private `.local/gateway/` paths. No external database is required.

The gateway image includes FFmpeg/ffprobe 8.0.1-r1 and CA certificates. It runs as the host UID/GID with a read-only root filesystem, no capabilities, SELinux-labelled mounts, 512 MiB and two CPUs. Probe concurrency is two; conversion concurrency is one. Local MP4/MKV/WebM can use direct play, remux or H.264 baseline conversion. Remote provider conversion is not implemented; provider URLs and credentials never enter FFmpeg arguments.

MediaMTX 1.21.1 has a 160 MiB/one-CPU budget. RTSP uses TCP port 8554. HLS 8888 and control API 9997 stay inside the Compose network. The gateway authenticates publishing/reading separately, proxies HLS and revokes the publisher when casting stops. A private callback key is generated by `make runtime-setup` and preserved in `compose.env`.

Both public listeners default to localhost. For physical devices, set `ZOMBIE_BIND_IP` to this machine's reachable LAN address in `.local/gateway/compose.env`, then rerun `make full-up`. Configure the Fedora firewall for TCP 8090/8554 on the intended LAN. USB deployment does not supply networking to the legacy TV box. No LAN/firewall change is performed automatically.

Configure provider credentials from the paired client or private server JSON/environment: [services and credentials](../docs/development/services-and-credentials.md). Optional YouTube runs with `make youtube-up` and remains resource-limited. Existing configuration is preserved.

See [mirroring](../docs/development/mirroring.md) for client/Cast installation and consent. Spotify Connect, UxPlay/AirPlay, Threadfin and Chromium Rebrowser now have optional pinned packages and gateway adapters. See their wrapper READMEs for account/device and feature gaps. `make services-build` prepares all images; `make services-up` enables them together. Heavy browser processes start only per session. The core default remains lightweight.
